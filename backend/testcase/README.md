# 测试文件

供各代码评测案例使用的示例提交。上传后由基座在隔离环境中运行，案例解析运行结果并评分，
通用静态分析与查重由基座统一处理。

## 案例 1 · 进程调度模拟器

- `case1_correct.py`：实现 FCFS、非抢占 SJF、时间片轮转和非抢占优先级调度，输出调度时间线、逐进程指标及平均性能指标，应通过全部 72 项功能检查。
- `case1_incorrect.py`：保持语法有效，但返回空结果，用于演示功能检查未通过的状态。

网页展示通过校验的调度甘特图及指标；桌面 GUI 与系统监控需另行验收。接口和评分范围见
[案例 1 接入说明](../../docs/cases/process-scheduler.md)。

## 案例 3 · 网络协议分析仪

- `case3_correct.py`：覆盖 ARP、ICMP、TCP 构造与解析、限量抓包、SYN 端口扫描检测和结构化输出。
- `case3_incorrect.py`：保持语法有效，但缺少绝大多数要求，并故意包含 `eval` 安全风险。

## 案例 5 · 算法复杂度分析平台

- `case5_correct.py`：实现冒泡/选择/快速/归并排序、顺序/二分查找，并包含多规模计时与复杂度拟合，应通过全部功能检查。
- `case5_incorrect.py`：保持语法有效，但只实现冒泡排序，故意使用非 snake_case 命名与 `eval`，用于演示未通过状态。

## 案例 7 · SQL 执行计划可视化工具

- `case7_correct.py`：解析 MySQL/PostgreSQL 文本执行计划，输出索引使用和全表扫描结果，
  并实现可返回查找路径的简化 B+ 树，应通过全部隔离运行检查。

启动后端后，在 Web 页面进入对应案例，上传上面的 `.py` 文件即可查看通过率、质量评分、
问题明细和提交内容差异。案例功能由隔离运行测试验证，PEP8、模块化程度和查重由基座处理。
