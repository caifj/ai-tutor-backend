# 测试文件

供各代码评测案例做静态分析的示例提交，后端不会执行这些文件。

## 案例 2 · 虚拟内存分页模拟器

- `case2_correct.py`：实现页表、地址转换、缺页中断处理、FIFO/LRU/OPT 三种置换算法、缺页率统计与多档内存页框数扫描，应 8/8 通过并得 100 分。
- `case2_incorrect.py`：保持语法有效，但无置换算法、内存页框数被硬编码，并故意使用 `eval`、`while True` 与 `global`，用于演示未通过状态。

## 案例 3 · 网络协议分析仪

- `case3_correct.py`：覆盖 ARP、ICMP、TCP 构造与解析、限量抓包、SYN 端口扫描检测和结构化输出。
- `case3_incorrect.py`：保持语法有效，但缺少绝大多数要求，并故意包含 `eval` 安全风险。

## 案例 5 · 算法复杂度分析平台

- `case5_correct.py`：实现冒泡/选择/快速/归并排序、顺序/二分查找，并包含多规模计时与复杂度拟合，应通过全部功能检查。
- `case5_incorrect.py`：保持语法有效，但只实现冒泡排序，故意使用非 snake_case 命名与 `eval`，用于演示未通过状态。

## 案例 7 · SQL 执行计划可视化工具

- `case7_correct.py`：解析 MySQL/PostgreSQL 文本执行计划，输出索引使用和全表扫描结果，
  并实现可返回查找路径的简化 B+ 树，应通过全部隔离运行检查。

问题明细和提交内容差异。案例功能由隔离运行测试验证，PEP8、模块化程度和查重由基座处理。
